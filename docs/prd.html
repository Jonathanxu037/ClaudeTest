    一、背景与目标

    1. 背景

    • 工单量大、返工多：账户与合规域的线上故障共 220 条，其中登录/token 46 条、OTP/短信 22 条、注册 17 条（主版第 1 章概况，统计截至 2026-10-07）。
    • 规则分散且多次变更：规则散落在工单、Axure 原型和后台配置里。比如 OTP 重发倒计时从 90s 改到 60s、30s，2026-02 起定为 45s（-1882、-2712、-3476）。
    • 多端表现不一致：两种登录方式回填的不是同一个账号（-4548）；人机弹窗出来前先报必填（-727、-740、-3536）；Telegram 登录在 iOS 偶发失败（-6420）。

    2. 目标

    1. 把注册、登录、找回密码、三方登录绑定手机号的现行规则整理成一份文档，作为各端开发和测试的统一依据。
    2. 列出资料之间的冲突和没有定值的地方，由产品确认后补齐。
    3. 配套可点击原型和功能自查清单，每个功能点对应规则、边界异常和验收标准。

    二、范围

    1. 做

    端范围说明
    H5 / PWA做主要入口；H5 限制海外 IP（-4492）
    PC做与 H5 同规则
    iOS 原生做含生物识别登录；Apple 登录去留见 Q3
    Flutter做含生物识别登录
    后台只用现有配置本期不新增后台功能，配置位置见第五章；因此本需求包不含后台原型和后台操作手册

    2. 不做

    • 安卓原生老包：靠服务端强更拦截，登录和注册时返回 2615（backend/1158698）。
    • KYC 流程（证件、人脸、补充信息）、NDRP 校验、3 天未 KYC 临时冻结：见主版第 1 章 R6–R10，本文只写和登录注册的衔接点。
    • Viber 登录（-6517，评审通过，子任务待开发）。
    • 活动规则：新用户转盘、登录送彩金等。
    • 789games 新站：※ 新站登录流程资料未覆盖，GAM 系列单只涉及注册送 ₱3 移除（GAM-1）和两站 KYC 互通（GAM-2）。

    三、业务规则

    1. 业务流程

    主流程从上到下；需要细讲的步骤点「见 3.1.x」跳到下方分支。v2.2
    1
    进入站点：冷启动 App 或打开 H5 → 弹出 21 岁确认弹窗 → 点 "I agree with all of the above"（F01）。
    • 广告来源 / App 下载页：不弹窗，直接进转盘（是否保留见 Q9）
    ↓
    2
    新用户转盘：按活动配置展示（不在本需求范围）→ 进入登录注册页。
    ↓
    3
    选择登录方式：验证码登录/注册、密码登录或三方登录 → 勾选条款（见 3.1.1）。
    • 记住上次登录：自动选中上次的方式并回填同一账号
    • Referral Code：只在邀请链接进入时显示，不可改
    ↓
    4
    完成验证：人机验证 → 短信验证码；或账号密码校验；或三方授权（见 3.1.1）。
    ↓
    5
    新用户补全：新手机号 → 自动建号 → 设置密码（可跳过）；三方首次登录 → 绑定手机号（可稍后）（见 3.1.2）。
    ↓
    6
    登录成功：进入首页 → iOS / Flutter 弹生物识别引导 → 新用户收到注册站内信。
    ↓
    7
    异常收尾（分支）：账号停用、冻结、老版本、H5 海外 IP、另一设备登录（见 3.1.3）。

    F02 登录注册页

    页面说明

    • F02-01页面结构：登录和注册合在一个页面（-753、-711）。两个 Tab：「验证码登录/注册」（默认）和「密码登录」。未注册的手机号通过验证码后自动建号。
    • F02-01手机号：必须以 09 开头、共 11 位，占位符 09XX XXX XXXX。获得焦点时自动填入 "0" 并调起数字键盘；用户输入 09 时自动去掉多出的 0。这条规则同样用于忘记密码、换绑手机号和提现绑卡（平台知识库 4.1）。
    • F02-02账号：最长 20 位，超长提示 "Content cannot exceed 20 characters"（-3383）；输入框 hint 为 "Phone/GCash/Maya"（平台知识库 4.1）。
    • F02-03条款勾选：文案 "I agree to 789's Terms…"，带链接；是否默认勾选由后台开关控制（冲突见 C5）。
    • F02-03Referral Code：只在通过邀请好友链接或代理链接进入时显示，自动带入且置灰不可改；其他情况隐藏（平台知识库 4.1）。
    • F02-04记住上次登录：自动记住上次使用的登录方式和账号；两种方式切换时保留手机号，回填同一个账号（-4548）。
    • F02-05登录间隔：两次登录至少间隔 30s，提示 "Please wait at least 30 seconds…"（-5069）。※ 前后端都要拦截，不能只做前端。
    • F02-06三方登录入口：Google、Facebook、Telegram；iOS 另有 Apple（-4956、-6093）。三方登录只在主域名开放。App 端入口范围见 Q3。
    • F02-01顶部 Banner：在后台「活动图素材管理 › 注册登录页」配置，排序值不可重复（平台知识库 4.1）。
    • F02-03底部文案：PAGCOR 标识和 21+ 提示。「删除登录注册页底部文案」一单已挂起（-5263），本期保留。

    F03 人机验证

    页面说明

    • F03-01验证码登录：点 Send code 后、发短信前触发；H5 绑定手机号也要过人机（-5457）。
    • F03-01验证类型：由后台 captchaType 决定，1 = Cloudflare Turnstile，2 = 腾讯滑块，0 或其他 = 数字图形码（-816）。2026-01 起手机号登录前先过 Cloudflare "Verifying..."（-1980、-4091）。
    • F03-02密码登录：命中风险规则时触发图片验证，由后台「图片验证规则触发」开关控制，触发原因要落库。命中任一即触发（平台知识库 4.1）：
      • 同一账号或同一 IP 5 分钟内登录失败 ≥ 3 次；
      • 近期改过登录密码或提款密码后的首次登录；
      • 新设备或设备指纹变化；模拟器、Root 设备；
      • 同一设备 1 分钟内登录 ≥ 3 个账号；同一 IP 5 分钟内登录超过 3 个账号；
      • 请求频率异常（0.1 秒内连续请求，或 send 接口 5 秒内 ≥ 3 次）；非正常 UA；异地 IP。

    边界异常

    • F03-01图形码位数不足：提示 "Please enter 4-digit verification code"（-2383）。
    • F03-01Cloudflare 不可用：「CF 异常时自动切换」和「恢复腾讯滑块」两个需求均被否决（-3866、-4044），只能由运营手动改 captchaType。
    • F03-02设备指纹误判：同一浏览器会产生多个设备指纹，是已知缺陷（-5963 评论），可能让「设备指纹变化」规则误触发。

    F04 短信验证码

    页面说明

    • F04-01格式：4 位数字，支持从剪贴板粘贴；发送成功提示 "Verification code sent successfully"（平台知识库 4.1）。
    • F04-01重发倒计时：45s，文案 "Resend code in 44 S"；关闭页面再进入时接着原倒计时走，不重置（-2712、-1882、-3476）。※ 以 45s 为准，平台知识库的 60s 已过时，见 C1。
    • F04-02供应商：首发走用户所属运营商；60s 内再次请求时轮换 Smart / Globe（-2712）。M360 返回 opted-out 时切到 Smart（-5152）；号码处于 OPTED_OUT 时给友好提示（-6230）。
    • F04-03错误次数：输错时提示 "Invalid verification code, you still have N times left"（-2264）。上限和锁定时长见 C2 和 Q1。
    • F04-04长时间未登录：超过后台「长时间未登录天数 OTP 设置」（needOtpLogin）的账号，密码登录时也要走短信验证；天数以后台配置为准（后台知识库 4.13.3）。
    • F04-05测试环境：UAT/QAT 验证码固定 0000，不真实发送（-6732，评审通过）。

    F05 设置密码

    页面说明

    • F05-02时机：验证码注册成功后引导设置登录密码，可跳过（是否改为必经步骤见 Q4）。
    • F05-01密码规则：8–16 位，必须同时含字母和数字，不允许中文、空格和表情；超出位数不能继续输入；两次输入要一致（-5545、平台知识库 4.1）。
    • F05-01服务端校验：服务端同样强制 8–16 位，不合规返回 code 15242（-5421）。
    • F05-01老用户：6–16 位的旧密码仍可登录，不强制修改（-853）。

    边界异常

    • F05-01绕过前端提交：直接调接口提交 7 位或 17 位密码，服务端拒绝（-5421）。
    • F05-01锁定：改密时旧密码校验失败若干次后锁定 60 分钟（code 1168，-5422）。登录失败的锁定阈值资料里没有定值（主版 R4），见 Q2。

    F06 三方登录绑定手机号

    页面说明
