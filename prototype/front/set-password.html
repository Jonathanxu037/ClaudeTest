规则批注

对应 PRD 功能点 F05。查看 PRD

  1. F05-018–16 位，同时含字母和数字，不允许中文、空格和表情；超出位数不能继续输入。-5545 平台知识库 4.1
  2. F05-01实时显示三条规则是否满足（N1，新增）；两次不一致提示 "Passwords do not match"，Save 不可点（N2，新增）。
  3. F05-01※ 服务端同样强制 8–16 位，不合规返回 code 15242，不能只靠前端拦。-5421
  4. F05-02新用户可点 Skip 进首页，之后在 Account Security 设置；是否改为必经步骤待 Q4。找回密码进入时没有 Skip，保存后回登录页。
  5. F05-02老用户 6–16 位旧密码仍可登录，不强制修改。-853
