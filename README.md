# 789 注册登录流程 · v2.2

需求包：可交互原型、需求开发 PRD 文档、功能自查清单。纯静态页面，不需要构建，也不调用任何接口。

## 版本

- 当前版本：v2.2（2026-10-07，修改人 Joshua）
- 状态：确认中

## 目录说明

| 路径 | 内容 |
|---|---|
| `index.html` | 入口页：需求概览和各部分链接 |
| `prototype/front/` | 8 个前台原型页面（21 岁弹窗、登录注册、人机验证、短信验证码、设置密码、三方绑定手机号、找回密码、登录成功） |
| `docs/prd.html` | 需求开发 PRD 文档 |
| `docs/checklist.html` | 功能自查清单（勾选状态只保存在当前浏览器） |
| `assets/` | 公共样式、目录栏（`nav-data.js` 是唯一的目录数据）、原型公共脚本 |
| `.nojekyll` | 让 GitHub Pages 按原样发布 |

本需求不新增后台功能，所以没有后台页面和后台操作手册。

## 本地查看

双击 `index.html` 即可，左侧目录栏可以跳转到所有页面。

## 发布到 GitHub Pages

1. 把整个 `register-login` 文件夹复制到仓库里。
2. 提交并推送。
3. 在仓库的 Settings › Pages 里，选择发布分支和目录。
4. 发布后访问 `<Pages 地址>/register-login/`。

发布前确认仓库的可见范围：PRD 里有平台内部的业务规则。
